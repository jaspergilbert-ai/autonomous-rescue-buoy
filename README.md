# Autonomous Rescue Buoy

Open-source Raspberry Pi system that detects a person in difficulty in the water, alerts responders, and launches a self-propelled rescue buoy with a tow line.

Built for the PA Raspberry Pi Competition 2027.

## What it does

A self-propelled buoy is stored in a case designed to look like a defibrillator case. When the system detects that a person is drowning, it:

1. Releases a rope into the water
2. Sends a message to the appropriate authorities
3. Moves the buoy towards the person to help them up
